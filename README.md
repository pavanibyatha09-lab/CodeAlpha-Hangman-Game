# 🎮 CodeAlpha Hangman Game

## 📌 Project Description
This is a Python-based Hangman Game developed as part of the CodeAlpha Python Programming Internship.

## ✨ Features
- Welcome Screen
- Game Rules
- Random Word Selection
- Clue System
- Input Validation
- Hangman Drawing
- Lives Counter
- Wrong Letter History
- Score Board
- Guess Counter
- Play Again Option

## 🛠️ Technologies Used
- Python 3

## ▶️ How to Run
1. Open the project folder.
2. Open Terminal.
3. Run:
   python hangman.py
